E-Commerce Trend Analysis (MySQL)

This project contains all the SQL queries I worked on during my internship to analyze an e-commerce dataset. The analysis focuses on understanding sales trends, customer behaviour, product performance, and inventory movement.

1) Project Overview
Using MySQL Workbench, I wrote multiple queries to explore and analyze different parts of the dataset, such as orders, customers, products, categories, and stock levels.

2) What I Did
- Cleaned and explored tables using SQL
- Analyzed monthly order and sales trends
- Identified top-selling products and categories
- Studied customer behaviour (new vs. returning customers)
- Checked inventory levels and slow-moving items
- Calculated revenue, order counts, and average order value

3) Tools Used
- MySQL Workbench  
- MySQL Server  
- SQL (Joins, subqueries, aggregate functions, window functions)

4) File Included
- **queries.sql** – Contains all SQL queries written during the analysis

5) About This Repository
This repository showcases the SQL scripts I created during my internship to extract insights from an e-commerce dataset. It reflects my understanding of data analysis using SQL.
